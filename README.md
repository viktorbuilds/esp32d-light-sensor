# How to Use an Open-Smart Light Sensor with ESP32

[Read more](https://viktorbuild.com/tutorials/how-to-use-an-open-smart-light-sensor-with-esp32/)

## Wiring

| Open-Smart light sensor | ESP32-D |
| --- | --- |
| VCC | 3.3V |
| GND | GND |
| SIG | GPIO34 |

Open the Serial Monitor at 115200 baud. The sketch prints a new raw
ADC reading every 250 milliseconds.
